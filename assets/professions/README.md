# Иконки профессий

По одной на каждую укрупненную профессию. 64 × 64, плоские заливки —
тот же стиль, что у исторических картинок в `data/history.js`.

Цвета — фирменная палитра из брендбука, токены `--brand-*` в
`styles/tokens.css`. Темно-синий, синий и серые держат рисунок,
яркие шесть идут акцентами. Фолбэк прямо в файле нужен, чтобы иконка
не потерялась, если открыть ее отдельно или вставить через `<img>`.
